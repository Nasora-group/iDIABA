# Architecture\n\n## Socle proposé\n- Next.js App Router + TypeScript pour interface et API.\n- Supabase/PostgreSQL : authentification, base, stockage.\n- Render pour hébergement applicatif selon choix du déploiement.\n- PWA et IndexedDB pour le mode hors connexion.\n\n## Multi-tenant\nChaque donnée métier porte un tenant_id. Les rôles sont définis au niveau entreprise et éventuellement établissement. La Row Level Security (RLS) est activée pour toutes les tables métier. Aucun accès inter-tenant n'est permis.\n\n## Domaines\nOrganisation, utilisateurs/permissions, catalogue, stock, ventes, achats, caisse, finance, comptabilité, reporting, abonnement et audit.\n\n## Règles d'intégrité\nMontants en NUMERIC/decimal, pas en float. Une vente validée n'est pas modifiée directement : annulation/retour et écritures correctives. Le stock est reconstruit depuis les mouvements. Toute opération synchronisée hors-ligne utilise un UUID idempotent.
